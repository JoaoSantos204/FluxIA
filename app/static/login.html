Autenticação com o Google

A integração de Login via Google (OAuth2 / OpenID Connect) já está integrada à plataforma!

🚀 Para ativar em produção: adicione a variável de ambiente GOOGLE_CLIENT_ID com o Client ID gerado no Google Cloud Console.
Passos rápidos no Google Cloud:
1. Acesse o Google Cloud Console.
2. Crie uma credencial de ID do cliente OAuth 2.0 (Aplicativo da Web).
3. Em Origens JavaScript autorizadas, adicione o domínio do seu FluxIA.
4. Configure GOOGLE_CLIENT_ID nas variáveis de ambiente.
